Integritetspolicy

Vi värnar om din integritet. I den här integritetspolicyn förklarar vi hur vi hanterar uppgifter som samlas in via vår webbplats (www.sanapsis.com) och våra appar SanapsisPro och Sanapsis+.

Personuppgiftsansvarig för dina personuppgifter är Puheklinikka Oy (Sanapsis) i Finland. Du kan kontakta oss på sanapsis@puheklinikka.net.

Uppgifter vi samlar in

Webbplatsen (www.sanapsis.com):

  • Uppgifter som du frivilligt ger oss (till exempel namn och e-postadress när du kontaktar oss direkt, via supportformulär eller i enkäter).
  • Kakor (cookies) för att förbättra webbplatsens funktion och användarupplevelsen.
  • Vi samlar inte in känsliga personuppgifter (till exempel ekonomiska uppgifter eller hälsouppgifter).

Apparna (SanapsisPro och Sanapsis+):

  • Vi samlar inte in, lagrar eller delar några personuppgifter via våra appar.
  • Våra appar har inte åtkomst till platsuppgifter, kontakter, foton eller enhetsidentifierare.
  • Sanapsis+ använder mikrofonen så att du kan lyssna på ditt eget tal. Inspelningarna sparas eller delas inte.
  • Ingen registrering eller inloggning krävs för att använda apparna.
  • Inga analys- eller annonstjänster eller spårningsverktyg från tredje part används.

Hur vi använder dina uppgifter

Vi använder uppgifter som samlas in via vår webbplats för att svara på förfrågningar och ge kundsupport, förbättra vår webbplats och våra tjänster samt informera dig om uppdateringar, erbjudanden eller ändringar i denna integritetspolicy (om du har samtyckt till det). Vi säljer, hyr ut eller delar inte dina personuppgifter med tredje part, utom när det behövs för att uppfylla din begäran eller rättsliga förpliktelser.

Rättslig grund för behandlingen (GDPR)

Om du befinner dig inom Europeiska ekonomiska samarbetsområdet (EES) behandlar vi dina personuppgifter på följande rättsliga grunder:

  • Ditt samtycke – för kontakt som du själv tar med oss
  • Berättigat intresse – för att driva, underhålla och förbättra våra tjänster och vår kommunikation

Lagring av uppgifter

Vi sparar korrespondens med användare endast så länge som det behövs för det ursprungliga syftet eller för att uppfylla rättsliga förpliktelser.

Inga uppgifter om appanvändare samlas in eller sparas.

Dina rättigheter enligt GDPR

Om du befinner dig inom Europeiska ekonomiska samarbetsområdet (EES) har du följande rättigheter när det gäller dina personuppgifter:

  • Rätt till tillgång – begära en kopia av de uppgifter vi har om dig.
  • Rätt till rättelse – begära att vi rättar eller uppdaterar dina uppgifter.
  • Rätt till radering (”rätten att bli bortglömd”) – begära att vi raderar dina personuppgifter.
  • Rätt att invända – invända mot hur vi behandlar dina uppgifter när behandlingen grundar sig på berättigat intresse.
  • Rätt till begränsning av behandling – begära att vi begränsar hur vi använder dina uppgifter.
  • Rätt till dataportabilitet – få dina uppgifter i ett strukturerat, maskinläsbart format.
  • Rätt att lämna in klagomål – lämna in ett klagomål till din lokala dataskyddsmyndighet.

Om du vill utöva någon av dessa rättigheter, kontakta oss på sanapsis@puheklinikka.net.

Om du anser att vi har kränkt dina rättigheter enligt GDPR har du rätt att lämna in ett klagomål till din lokala dataskyddsmyndighet.

Din tillgång till och kontroll över uppgifterna

Du kan när som helst tacka nej till framtida kommunikation från oss genom att kontakta oss på sanapsis@puheklinikka.net. Du kan se vilka uppgifter vi har om dig (om några), begära rättelse eller uppdatering, begära att dina uppgifter raderas eller framföra synpunkter på hur vi använder dina uppgifter.

Säkerhet

Vi vidtar lämpliga tekniska och organisatoriska åtgärder för att skydda dina uppgifter. Kommunikationen på webbplatsen krypteras med SSL/TLS-protokoll. Åtkomst till personuppgifter är begränsad till de anställda som behöver dem för kundsupport. Våra servrar finns i säkra lokaler. Vi samlar inte in känsliga uppgifter (såsom ekonomiska uppgifter eller hälsouppgifter) via vår webbplats eller våra appar.

Kakor

Vår webbplats använder kakor för att känna igen återkommande besökare, spara användarinställningar och analysera trafiken på webbplatsen. Kakorna förbättrar webbplatsens funktion men är inte kopplade till uppgifter som kan identifiera dig personligen. Du kan styra inställningarna för kakor i din webbläsare.

Länkar till andra webbplatser

Vår webbplats kan innehålla länkar till externa webbplatser. Vi ansvarar inte för innehållet eller integritetspraxis på dessa webbplatser. Vi uppmanar dig att läsa integritetspolicyn för de webbplatser du besöker.

Enkäter och tävlingar

Deltagande i enkäter eller tävlingar på vår webbplats är helt frivilligt. Uppgifter som samlas in (till exempel namn, adress eller demografiska uppgifter) används endast för att genomföra enkäten eller tävlingen och för att meddela vinnarna.

Ändringar i denna integritetspolicy

Vi kan uppdatera denna integritetspolicy vid behov. Betydande ändringar publiceras på den här sidan och meddelas vid behov direkt till dig.
